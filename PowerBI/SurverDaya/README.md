# Power BI – Data Career & Job Satisfaction Survey Analysis

## 📊 Project Overview

This Power BI project analyzes survey responses from people working in the data field. The goal is to understand the **demographics, career backgrounds, compensation, and job satisfaction** of survey participants.

The dashboard explores questions such as:

- Who are the people working in data?
- What roles and industries do they work in?
- How many people switched careers into data?
- How does salary vary across roles, industries, and demographics?
- Which factors contribute most to job satisfaction?
- How difficult was it for respondents to break into the data field?
- What do people value most when considering a new job?

The project focuses on turning raw survey responses into an interactive and easy-to-understand report using **Power BI**.

---

## 🛠️ Tools Used

- **Power BI**
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and calculated fields
- **Data Visualization** – Interactive charts, cards, slicers, and tables

## 📋 Dataset

The dataset contains survey responses from individuals about their careers in the data field.

### Survey Columns

| Column | Description |
|---|---|
| `UniqueID` | Unique identifier for each survey respondent |
| `Email` | Anonymous email identifier |
| `Date Taken` | Date the survey was completed |
| `Time Taken` | Time the survey was completed |
| `Browser` | Browser used to complete the survey |
| `OS` | Operating system used |
| `City` | City of the respondent |
| `Referrer` | Survey referral source; mostly blank |
| `Time Spent` | Time spent completing the survey, in minutes |
| `Q1 – Current Role` | Current job title/role |
| `Q2 – Career Switch` | Whether the respondent switched careers into data |
| `Q3 – Yearly Salary` | Current yearly salary in USD |
| `Q4 – Industry` | Industry in which the respondent works |
| `Q5 – Favorite Programming Language` | Respondent's preferred programming language |
| `Q6 – Job Satisfaction` | Satisfaction ratings from 1–10 across several areas |
| `Q7 – Difficulty Breaking into Data` | Respondent's perception of how difficult it was to enter the data field |
| `Q8 – Important Job Factor` | Most important factor when looking for a new job |
| `Q9 – Gender` | Male/Female |
| `Q10 – Age` | Current age |
| `Q11 – Country` | Country of residence |
| `Q12 – Education` | Highest level of education |
| `Q13 – Ethnicity` | Respondent's ethnicity |

### Job Satisfaction Metrics

Question 6 measures satisfaction on a **1–10 scale** across:

- 💰 Salary
- ⚖️ Work/Life Balance
- 👥 Coworkers
- 👔 Management
- 📈 Upward Mobility
- 📚 Learning New Things

## 🎯 Project Goals

The main objective of this project is to practice using Power BI to:

1. Clean and transform survey data.
2. Build an appropriate data model.
3. Create meaningful DAX measures.
4. Analyze demographic and career trends.
5. Compare salary and job satisfaction.
6. Build an interactive dashboard.
7. Present findings in a way that can be understood by a non-technical audience.

## 💡 Key Takeaways

The dashboard is designed to allow users to interactively explore how **career background, demographics, salary, and workplace satisfaction** vary among people working in data.

Rather than focusing only on overall averages, the report allows these factors to be explored using filters and comparisons across different groups.

## 📌 Disclaimer

The analysis is based on survey responses and reflects the characteristics of the respondents included in the dataset. The results should therefore not be interpreted as representative of the entire data industry or workforce.
